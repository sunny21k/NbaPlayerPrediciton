# NBA Player Performance Predictor

A machine learning project built with Python that predicts NBA player statistics such as points, assists, and rebounds using historical player data and linear regression models.

## Overview

This project analyzes NBA player performance data and uses machine learning techniques to predict future player statistics. The model was trained using historical NBA datasets and improved through data preprocessing, feature engineering, and cleaning techniques.

## Features

- Predicts:
  - Points
  - Assists
  - Rebounds
- Data preprocessing and cleaning
- Feature engineering for improved model accuracy
- Linear regression machine learning model
- Performance evaluation and accuracy testing
- Data analysis using pandas and numpy

## Technologies Used

- Python
- pandas
- numpy
- scikit-learn
- matplotlib (optional for visualization)

## How It Works

1. NBA player data is collected and loaded into pandas DataFrames.
2. Data is cleaned by handling missing values and formatting inconsistencies.
3. Relevant features are selected and engineered for better predictions.
4. A linear regression model is trained on historical player performance data.
5. The model predicts future player statistics and evaluates prediction accuracy.

## Example Use Cases

- Predicting player performance trends
- Comparing player efficiency
- Sports analytics and visualization
